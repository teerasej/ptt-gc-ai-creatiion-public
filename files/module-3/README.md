# Module 3 Knowledge Files

ใช้ไฟล์ Markdown สี่ไฟล์นี้เป็น Knowledge ของ `PTT GC Operations Knowledge Assistant`

- `operations-overview.md` สำหรับคำถามภาพรวม
- `downtime-reporting.md` สำหรับขั้นตอนแจ้ง downtime
- `maintenance-escalation.md` สำหรับระดับการ escalation
- `operations-roles.md` สำหรับบทบาทและความรับผิดชอบ

ไฟล์ทั้งหมดเป็นสถานการณ์จำลองและออกแบบให้มีบางคำถามที่ตอบได้จากหลายแหล่ง เพื่อให้ผู้เรียนเห็นความต่างระหว่าง broad และ targeted retrieval
