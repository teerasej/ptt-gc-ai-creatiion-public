# Downtime Reporting

เอกสารจำลองนี้ใช้สำหรับการฝึกอบรมเท่านั้น

## Required Record

เมื่อพบ unplanned downtime ให้บันทึกข้อมูลต่อไปนี้โดยไม่คาดเดา

- วันที่และเวลาที่เริ่มพบเหตุ
- พื้นที่และ equipment tag หากทราบ
- อาการที่สังเกตเห็นจริง
- สถานะการผลิตที่ได้รับผลกระทบ
- ผู้ที่ได้รับแจ้งและเวลาที่แจ้ง
- การดำเนินการตาม approved procedure

## Reporting Steps

1. แจ้ง Control Room Operator ทันที
2. Control Room Operator บันทึก event log และแจ้ง Shift Supervisor
3. Shift Supervisor ตรวจความครบถ้วนและกำหนดการประสานงานถัดไป
4. หาก downtime เกิน 30 นาที ให้สร้าง preliminary downtime summary
5. ห้ามระบุ root cause เป็นข้อสรุปจนกว่าผู้รับผิดชอบจะยืนยัน
