# Operations Overview

เอกสารจำลองนี้ใช้สำหรับการฝึกอบรมเท่านั้น

## Operating Priorities

1. ความปลอดภัยของบุคลากรและพื้นที่ทำงาน
2. การควบคุมสถานการณ์ตาม approved operating procedure
3. การบันทึกข้อเท็จจริงและเวลาที่เกิดเหตุ
4. การแจ้งผู้รับผิดชอบตามระดับของเหตุการณ์
5. การทบทวนสาเหตุและการป้องกันการเกิดซ้ำ

## General Guidance

- ผู้พบเหตุควรแจ้ง Control Room Operator หรือ Shift Supervisor ตามช่องทางที่กำหนด
- ห้ามใช้ Agent เป็นคำสั่งควบคุมอุปกรณ์หรือแทน emergency procedure
- หากข้อมูลใน Knowledge ไม่ครอบคลุม ให้หยุดและตรวจสอบกับ Shift Supervisor
