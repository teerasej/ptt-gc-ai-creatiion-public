# Operations Roles

เอกสารจำลองนี้ใช้สำหรับการฝึกอบรมเท่านั้น

| Role | Responsibility in this scenario |
|---|---|
| Field Operator | สังเกตอาการ แจ้งเหตุ และบันทึกข้อเท็จจริงจากหน้างาน |
| Control Room Operator | บันทึก event log ประเมินผลกระทบเบื้องต้น และแจ้ง Shift Supervisor |
| Shift Supervisor | ตรวจข้อมูล ประสานงาน และกำหนด escalation ที่เหมาะสม |
| Maintenance Coordinator | รับและจัดคิวงาน maintenance ระดับ 1 |
| Maintenance Supervisor | ดูแลงานระดับ 2 และประสาน resource |
| Maintenance Manager | รับ escalation ระดับ 3 ตาม site process |

Agent ไม่มีบทบาทอนุมัติการปิดระบบ เปลี่ยน operating limit หรือสั่งงานบุคลากร
