# Module 4 Support Files

ใช้ไฟล์เหล่านี้กับ `Financial Report Assistant`

- `PTT-Monthly-Financial-Report-May2026.xlsx` เป็น workbook จำลองสำหรับ Prompt analysis
- `financial-report-technical-terms-knowledge.docx` เป็น optional Knowledge เรื่องคำศัพท์
- `financial-report-distribution-policy-knowledge.docx` เป็น optional Knowledge เรื่องขอบเขตการแจกจ่ายรายงาน

## Workbook Structure

1. `Summary` แสดง Revenue, Cost, Variance, Status และ Key Risk ตาม Business Unit
2. `Revenue` แสดงรายได้ตาม Product Category
3. `Costs` แสดงค่าใช้จ่ายเทียบ budget
4. `Variance_Analysis` แสดง Actual, Budget และ root cause จำลอง

> **⚠️ Note:** ใช้ข้อมูลจำลองเท่านั้น หาก Prompt file input ไม่พร้อม ให้ใช้ prepared Prompt output ของผู้สอนเพื่อทำ revision และ Agent Flow ต่อ
